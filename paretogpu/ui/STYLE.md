# ParetoGPU — как верстать страницы

Обязательно для любой новой HTML-страницы или раздела ParetoGPU: окно (`ui/static/`: `index.html`, `app.css`, `js/`), отчёт кадра
(`views/templates/frame_report.html`), сравнение (`views/templates/result_view.html`), таблица функций (`docs/index.html`) и всё новое.
Цель — один вид везде: тёмная тема «Mint Editor», спокойные цвета, плотные, но читаемые таблицы.

## 1. Токены: `paretogpu/views/static/theme.css`

Палитра и шрифты — в одном файле. Окно подключает его как `/shared/theme.css`, отчёты получают его встроенным
(`views/html.py`), сайт — копией `docs/theme.css` (её кладёт `python -m paretogpu bench`). Меняете цвет — меняйте
только там. Своё у страницы (например, `--heat-*` таблицы функций) — в её `<style>` после темы.

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&family=IBM+Plex+Mono:wght@400;500;600&display=swap" rel="stylesheet">
<link rel="stylesheet" href="theme.css">
<style>
body { margin: 0; background: var(--bg); color: var(--text); font: 14px/1.45 var(--sans); font-variant-numeric: tabular-nums; }
</style>
```

- Тема только тёмная. Светлой темы и переключателя нет.
- В CSS и JS — только `var(--…)`, никаких новых hex. Нужен новый цвет — добавить токен во все страницы.
- Фон не чёрный, текст не белый. Глубина — светлотой: `--bg` (страница) → `--panel` (карточка) → `--chip` (вложенное).
  Тени не нужны.

## 2. Что значит каждый цвет

| Токен | Только для |
|---|---|
| `--accent` (мята) | интерактив: основная кнопка, активная вкладка/сегмент, ссылки, фокус, прогресс, выбранная карточка. **Никогда для цифр и статусов** |
| `--cheap` / `--heavy` | дешевле / дороже, стало лучше / хуже, ошибки. Только у дельт и статусов |
| `--medium` | предупреждение: «внимание, но не ошибка» (регистров > 32, неточный подсчёт) |
| `--info` | нейтральные пометки: «новый», «B», динамический цикл |
| `--bar` | полоски величины (доля кадра, цена). Величина — не оценка, поэтому серая |
| `--part-px/vx/cs`, `STAGE_COLORS` | категории (пиксели / вершины / compute, стадии кадра). Статусные цвета для категорий не брать |

Цвет никогда не единственный носитель смысла (WCAG 1.4.1, дальтоники): у дельты всегда знак (`+5.6%`, `−3.8`),
у флага — текст или значок `⚠`, у предупреждения — `!`.

## 3. Типографика

- Текст — Manrope, числа в таблицах и коде — IBM Plex Mono (`font-family: var(--mono)`), цифры моноширинные.
- Размеры: 11 (подписи, метки) · 12–13 (таблицы, вторичное) · 14 (основной) · 15–16 (h2) · 20–22 (h1, ключевые цифры).
- Жирный — для заголовков и главного числа строки (итог), не для середины предложения.
- Тексты по-русски, коротко; единицы измерения — в заголовке колонки («Итог, млн», «Цикл / пикс»), а не в каждой ячейке.

## 4. Иерархия страницы: «сначала главное, детали по запросу»

1. Заголовок + одна строка контекста (проект, ядро, API, дата) мелким `--muted`.
2. Ключевые цифры — карточки-метрики или вердикт (крупно, одним предложением: «B дешевле A на 5.6%»).
3. Управление (ядро, группировка, поиск, n) — одной полосой `.controls`/`.tools` с сегментами `.seg`.
4. Таблица. Всё, что не нужно для сравнения строк, — в раскрытую строку (п. 5.2).
5. «Как читать» — в `<details>` внизу шапки, свёрнуто.

На экране один главный акцент. Если подсвечено всё — не подсвечено ничего.

## 5. Таблицы

### 5.1 Сетка
- **Одна строка = одна сущность, одна линия текста.** Ни одной ячейки в 2–4 строки. Длинное — `text-overflow: ellipsis` +
  полное значение в `title`.
- `table-layout: fixed` + `<colgroup>` с явными ширинами. Без этого браузер раздаёт ширину по содержимому, и колонки «едут».
- **Таблицы одного раздела — на одной сетке:** одинаковая ширина колонки-подписи и числовых колонок, одинаковый порядок
  (`A | B | B − A`), чтобы одни и те же величины стояли друг под другом. Пример — `cols(n)` в `result_view.html`
  (подпись 210px, число 96px, `width: auto` у таблицы).
- Узкие таблицы (несколько чисел) — шириной по содержимому, а не на весь экран. Широкие — `max-width: 1400px`.
- Числа — по правому краю, моноширинные; текст — по левому; заголовок выровнен как его данные.
- Колонок 5–8. Главная колонка (то, по чему сортируют и решают) — первой или последней, и самой заметной
  (итог — жирный, доля — с полоской `--bar`).
- Группы колонок (длинный путь / короткий / всего) разделять тонкой вертикальной линией (`.gl`), заголовок группы — над ней.
- Строки — тонкие разделители `--line` и подсветка при наведении `--hover`. «Зебру» не делать.
- Шапка `position: sticky` у длинных таблиц. Сортировка — клик по заголовку, стрелка ↓/↑, отсортированная колонка — `--accent`.

### 5.2 Детали по клику (раскрытие строки)
Всё вторичное (методы подсчёта, регистры, keywords, RT, батч, разбивки, «накоплено») — не в строке, а в строке-детали:

```js
// st.open: Set ключей раскрытых строк; ключ стабильный (индекс события, "g:<группировка>:<ключ>")
h += `<tr class="r ${open ? "open" : ""}" data-g="${key}">…</tr>`;
if (open) h += `<tr class="det"><td colspan="N"><div class="dg num">
  <div><span>Подпись</span>значение</div>…</div><div class="dl">чипы keywords / флагов</div></td></tr>`;
// после рендера:
document.querySelectorAll("tr.r").forEach(el => el.onclick = () => { toggle(el.dataset.g); render(); });
```

- В заголовке таблицы — «клик по строке — подробности».
- Деталь — сетка `.dg` (подпись `--muted` 11px сверху, значение снизу), ниже чипы `.kw`.

### 5.3 Компактные пометки в строке
- Стадия / категория — цветная точка `.dot` перед названием (цвет из `STAGE_COLORS`), текст — в `title`.
- Флаги — один счётчик `.fc`: серый `3`, красный `⚠ 4`, если есть плохие (spilling, регистров > 32). Список — в `title`
  и в деталях.
- Батч / несколько объектов — первое имя + `+2` серым, полный список в `title`.
- Метод подсчёта (diff, mesh, renderdoc) — не в каждой ячейке, а в деталях и в «Как читать». В строке — только если он
  нестандартный и влияет на доверие к числу (`!` с подсказкой).

## 6. Компоненты

| Что | Класс / как |
|---|---|
| Карточка | `background: var(--panel); border: 1px solid var(--line); border-radius: 12px; padding: 14px 16px` |
| Метрика | `--chip`, подпись 12px `--muted`, число 20–22px, дельта под ним со знаком |
| Вердикт | `.verdict`: полоса слева `--cheap`, одно предложение 19px, под ним строка деталей `--muted` |
| Кнопка | `.btn` — `--panel` + рамка `--line`; основная `.btn.primary` — `--accent`, текст `--on-accent`. Одна основная на экран |
| Сегменты | `.seg` — переключатели (ядро, группировка, n). Выбранный — `--accent` + `--on-accent` |
| Бейдж статуса | `color: X; background: color-mix(in srgb, X 14%, transparent); border-radius: 999px; font-size: 11px` |
| Чип keyword | `.kw`/`.kwc` — `--chip`, моно 11–12px |
| Предупреждение | `.warn`: полоса слева `--medium`, фон `--medium` 10% |
| Пустое состояние | `.empty`: по центру, `--muted`, что делать дальше («Снимите кадр во вкладке …»), а не пустая таблица |
| Полоска величины | `--bar`, высота 6–8px, радиус 3px; ширина — доля от максимума в таблице |

Радиусы: 6–8px контролы, 10–12px карточки. Отступы кратны 4px.

## 7. Числа

- Одна точность на колонку: циклы `36.0` / `5.40` (`cyc`), млн циклов `55.0` (`mc`), проценты `24.7%` / `2.09%` (`pc`).
- Разделитель тысяч — пробел (`toLocaleString("ru-RU")`).
- Дельта — всегда со знаком (`+`, `−` — настоящий минус U+2212, `±`/`=` для нуля) и цветом `cls()`: меньше — `--cheap`.
- Пусто — `—`, не `0` и не `null`.

## 8. Чек-лист перед тем, как отдать страницу

- [ ] Токены вставлены блоком из п. 1, новых hex нет.
- [ ] Мята только на интерактиве; красный/зелёный только у дельт и статусов; у каждого цветного смысла есть знак или текст.
- [ ] Каждая строка таблицы — одна линия; вторичное — в раскрытии; колонки на `colgroup`, таблицы раздела выровнены.
- [ ] Числа справа, моноширинные, с единицей в заголовке.
- [ ] Есть пустое состояние и понятные ошибки.
- [ ] Проверено в браузере на 1600px и 1000px ширины: ничего не «едет», нет горизонтальной прокрутки страницы.
  Выравнивание колонок проверяется так:
  `[...document.querySelectorAll("table")].map(t => [...t.querySelectorAll("tr:last-child td")].map(td => td.getBoundingClientRect().left))`
- [ ] Отчёты, собранные генератором (report.py, compare.py, matcompare.py), пересобраны из своего JSON — старые HTML
  остаются в старом виде.
